# Employee Data Analysis using Python & Pandas

## 📌 Project Overview
This project analyzes employee data using Python and Pandas to understand salary, department, gender, age, and experience patterns.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Analysis Performed
- Total number of employees
- Average salary
- Highest and lowest salary
- Department-wise employee count
- Department-wise average salary
- Gender-wise employee distribution
- Salary distribution
- Average age and experience
- Highest-paid employee

## 📈 Visualizations
- Employees by Department
- Average Salary by Department
- Employees by Gender
- Salary Distribution

## 💡 Key Insights
- Analyzed employee distribution across different departments.
- Compared average salaries between departments.
- Identified the highest and lowest salary.
- Analyzed employee age and experience.
- Studied gender distribution across departments.
